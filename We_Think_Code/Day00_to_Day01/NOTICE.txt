These are some of the Linux commands you will love to use
- ls: Lists all files and directories in your current location.
- cd: Changes your current directory (e.g., cd /home/user/Documents).
- pwd: Prints the full path of your current working directory.
- mkdir: Creates a new directory.
- touch: Creates a new empty file or updates the timestamp of an existing one
- cp: Copies files or directories from one location to another.
- mv: Moves or renames files and directories.
- rm: deletes files
